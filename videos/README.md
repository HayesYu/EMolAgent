# EMolAgent demonstration videos

**[Watch the edited demonstration online (1:08)](https://huggingface.co/datasets/Franklalalala/EMolStudio-review-bundle#emolagent-demo)**

For offline viewing, open **[edited_emolagent.mp4](edited_emolagent.mp4)** in a video player.
The **[original English recording, unedited (7:26)](original_EMolAgent_English_unedited.mp4)** is also included.

The edited recording provides a short view of the EMolAgent interface and workflow;
the original preserves the full recorded interaction. Both MP4 files are supplied unchanged.
File sizes, durations and SHA-256 checksums are recorded in `manifest.json`.

EMolAgent is developed and maintained by Huize Yu: https://github.com/HayesYu/EMolAgent.

The README uses `emolagent-preview.gif`, a silent looping preview of the full edited recording (720 px wide, 6 fps). Click the animation to open the full video player.
